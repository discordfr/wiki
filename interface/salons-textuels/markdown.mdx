La syntaxe **Markdown** se caractérise par le positionnement de caractères simples, tel que l'astérisque (<code>*</code>) et le hashtag (<code>#</code>), qui permettent la **mise en forme** d'un texte.

Par exemple, la syntaxe suivante :

```md
Le *pré* est rempli d'**animaux joyeux** chantant __gaiement__ ~~tant que le loup n'est pas là.~~
```

Apparaît tel que :

![Exemple de texte formatté avec Markdown](https://i.dfr.gg/c4Lm.webp)

## Syntaxe

### Formatage de texte

<Tabs defaultValue="gras" queryString="formatage-de-texte">
<TabItem value="italique" label="Italique">
1 astérisque (<code>*</code>) ou 1 underscore (<code>_</code>) de part et d'autre d'une chaîne de caractères affiche un texte en <i>italique</i>.

Par exemple, le message suivant :

```md
Bienvenue sur *dfr.*_gg_ !
```

A comme rendu :

![Texte en italique sur Discord](https://i.dfr.gg/NHBY.webp)
</TabItem>
<TabItem value="gras" label="Gras">
2 astérisques (<code>**</code>) de chaque côté d'un texte affiche un message en <strong>gras</strong>.

Par exemple, le message suivant :

```md
Bienvenue sur **dfr.gg** !
```

A comme rendu :

![Texte en gras sur Discord](https://i.dfr.gg/Jiuv.webp)
</TabItem>
<TabItem value="souligne" label="Souligné">
2 underscores (<code>__</code>) de chaque côté d'une chaîne de caractères affiche un texte <u>souligné</u>.

Par exemple, le message suivant :

```md
Bienvenue sur __dfr.gg__ !
```

A comme rendu :

![Texte souligné sur Discord](https://i.dfr.gg/aC0n.webp)
</TabItem>
<TabItem value="barre" label="Barré">
2 tildes (<code>~~</code>) de part et d'autre d'un texte affiche un message <s>barré</s>.

Par exemple, le message suivant :

```md
Bienvenue sur ~~dfr.gg~~ !
```

A comme rendu :

![Texte barré sur Discord](https://i.dfr.gg/LA24.webp)
</TabItem>
<TabItem value="spoiler" label="Spoiler">
2 barres verticales (<code>||</code>) de chaque côté d'un texte affiche un message <Spoiler>caché</Spoiler>.

Par exemple, le message suivant :

```md
Bienvenue sur ||dfr.gg|| !
```

A comme rendu :

![Texte caché sur Discord](https://i.dfr.gg/arCL.webp)

:::note
Après avoir cliqué sur la partie cachée, son contenu s'affiche :

![Texte visible après avoir cliqué sur le spoiler](https://i.dfr.gg/KkY5.webp)
:::
</TabItem>
<TabItem value="citation" label="Bloc de citation">
1 signe plus grand que (<code>&gt;</code>), au début de la ligne, affiche un texte sous :

> citation

Par exemple, le message suivant :

```md
> Bienvenue sur dfr.gg !
```

A comme rendu :

![Citation sur Discord](https://i.dfr.gg/vNMi.webp)

:::note
Placer 3 signes plus grand que (`>>>`), au début de la ligne, rendera automatiquement tout le reste du message sous citation.
:::
</TabItem>
<TabItem value="titres" label="Titres">
1, 2 ou 3 hashtags (<code>#</code>, <code>##</code>, <code>###</code>), en début de ligne, affiche un texte agrandi tel que :

<p style={{fontSize: "var(--ifm-h1-font-size)"}}>Titre 1</p>
<p style={{fontSize: "var(--ifm-h2-font-size)"}}>Titre 2</p>
<p style={{fontSize: "var(--ifm-h3-font-size)"}}>Titre 3</p>

Par exemple, le message suivant :

```md
# Bienvenue sur dfr.gg !
## Ce site est contributif.
### Bonne visite !
```

A comme rendu :

![Titres sur Discord](https://i.dfr.gg/IwhK.webp)
</TabItem>
<TabItem value="petit" label="Sous-texte">
Un tiret suivi d'un hashtag (<code>-#</code>), en début de ligne, affiche un petit texte gris tel que :

<small>Bienvenue sur dfr.gg !</small>

Par exemple, le message suivant :

```md
-# Bienvenue sur
dfr.gg !
```

A comme rendu :

![Sous-texte sur Discord](https://i.dfr.gg/7D4S.webp)
</TabItem>
</Tabs>

### Bloc de code

<Tabs defaultValue="multiligne" queryString="bloc-de-code">
<TabItem value="uniligne" label="Bloc uniligne">
1 accent grave (<code>&#96;</code>) de chaque côté d'un texte affiche un message sous la forme de `bloc`.

Par exemple, le message suivant :

```md
Bienvenue sur `dfr.gg` !
```

A comme rendu :

![Bloc de code uniligne sur Discord](https://i.dfr.gg/hg5r.webp)
</TabItem>
<TabItem value="multiligne" label="Bloc multiligne">
3 accents grave (<code>```</code>) de chaque côté d'un texte affiche un message sous la forme de

```
bloc
```

Il est aussi possible, mais non-obligatoire, de rajouter l'[alias d'un langage](https://github.com/volcanofr/volcanofr/blob/main/supported_languages.md),
après les caractères d'ouverture du bloc.

Tel que :

```
```diff
- discord.fr
+ dfr.gg
  slash.fr.community
``` 
```

A comme rendu :

![Bloc de code multiligne sur Discord (langage diff)](https://i.dfr.gg/Nbpo.webp)

:::note
Il est aussi possible d'utiliser l'alias `ansi` afin de customiser les couleurs du bloc de code.
Un générateur de code ansi est disponible [ici](https://rebane2001.com/discord-colored-text-generator).
:::
</TabItem>
</Tabs>

### Mentions

<Tabs defaultValue="utilisateur" queryString="mentions">
<TabItem value="utilisateur" label="Utilisateur de Discord">
La mention d'utilisateur se trouve sous le format <code>&lt;@identifiant&gt;</code>

Par exemple, le texte suivant :

```
<@1231631025914904576>
```

A comme rendu :

![Mention de Wumpus](https://i.dfr.gg/dz44.webp)

:::note
La mention devient orange lorsqu'elle est destinée à l'utilisateur.

![Mention de Wumpus](https://i.dfr.gg/Kx6z.webp)
:::

:::note
Le format <code>&lt;@!identifiant&gt;</code> est aussi utilisable, mais déconseillé.
:::
</TabItem>
<TabItem value="salon" label="Salon et fil">
La mention de salons se présente sous le format <code>&lt;#identifiant&gt;</code>.

Par exemple, le texte suivant :

```
<#264363166316756992>
```

A comme rendu :

![Mention d'un salon vocal](https://i.dfr.gg/ocqf.webp)

:::note
La mention de tout types de salons, posts, fils de discussion et messages privés est possible.
Les catégories sont aussi mentionables, mais ne seront pas cliquable.

Il est aussi possible d'utiliser le lien du salon afin de le mentionner.
:::
</TabItem>
<TabItem value="role" label="Rôle">
La mention des rôles se forme sous le format <code>&lt;@&amp;identifiant&gt;</code>.

Par exemple, le texte suivant :

```
<@&1120672019135090729>
```

A comme rendu :

![Mention d'un rôle](https://i.dfr.gg/WOgL.webp)
</TabItem>
<TabItem value="commande" label="Commande slash">
La mention des commandes d'application se fait sous le format <code>&lt;nom_commande (nom_groupe-sous-commande) (nom_sous-commande):identifiant&gt;</code>.

Par exemple, le texte suivant :

```
</serveur:942123323482054797> </event help:1090669974470803656>
```

A comme rendu :

![Mention des slash commandes](https://i.dfr.gg/7Ly6.webp)

:::note
Une commande n'a pas nécessairement de Subcommands et de Subcommand Groups, il n'est donc pas nécessaire de placer ces noms.
:::
</TabItem>
<TabItem value="message" label="Message">
La mention des messages se fait uniquement via leur lien de partage.

Par exemple, le texte suivant :

```
https://discord.com/channels/812028116552777738/909858896431161375/909905242466951168
```

A comme rendu :

![Mention d'un message](https://i.dfr.gg/PjfU.webp)

:::note
Si le message provient d'un autre serveur que celui d'origine, le nom du serveur s'affiche lorsque l'utilisateur est dessus.
![Mention d'un message externe](https://i.dfr.gg/TsMO.webp)
:::
</TabItem>
<TabItem value="jeu" label="Jeu">
La mention des jeux se forme sous le format <code>&lt;@$identifiant&gt;</code>.

Par exemple, le texte suivant :

```
<@$1410791091501928458>
```

A comme rendu :

![Mention d'un jeu](https://i.dfr.gg/cSnR.png)
</TabItem>
<TabItem value="special" label="Spécial">
Certains emplacements ont des mentions spéciales.

- <code>&lt;id:guide&gt;</code> mentionne le guide du serveur ;
- <code>&lt;id:browse&gt;</code> mentionne la recherche des salons ;
- <code>&lt;id:customize&gt;</code> mentionne les questions de personnalisation et l'affichage des salons ;
- <code>&lt;id:linked-roles&gt;</code> mentionne le menu des rôles liés, et <code>&lt;id:linked-roles:role_id&gt;</code> mentionne le menu sur un rôle lié spécifique ;

Par exemple, le texte suivant :

```
<id:guide> <id:browse> <id:customize> <id:linked-roles> <id:linked-roles:1053078378925789324>
```

A comme rendu :

![Mentions spéciales](https://i.dfr.gg/zPye.png)
</TabItem>
</Tabs>

### Unix Timestamp

Sur Discord, il est possible d'afficher une date et l'heure suivant la plage horaire et la langue locale de l'utilisateur.
Cette fonctionnalité est notamment très pratique pour afficher l'heure de réunions et d'évènements.

Pour mentionner un [timestamp](https://unixtime.org), il suffit de commencer par "<code>&lt;t:timestamp:</code>", puis de choisir l'une de ces lettres :

- `t` (heure courte) - <code>&lt;t:0:t&gt;</code> affiche "01:00" ;
- `T` (heure longue) - <code>&lt;t:0:T&gt;</code> affiche "01:00:00" ;
- `d` (date courte) - <code>&lt;t:0:d&gt;</code> affiche "01/01/1970" ;
- `D` (date longue) - <code>&lt;t:0:D&gt;</code> affiche "1 janvier 1970" ;
- `f` (date longue et heure courte) - <code>&lt;t:0:f&gt;</code> affiche "1 janvier 1970 01:00" ;
- `F` (date entière et heure courte) - <code>&lt;t:0:F&gt;</code> affiche "jeudi 1 janvier 1970 01:00" ;
- `s` (date et heure courtes) - <code>&lt;t:0:s&gt;</code> affiche "01/01/1970 01:00" ;
- `S` (date courte et heure longue) - <code>&lt;t:0:S&gt;</code> affiche "01/01/1970 01:00:00" ;
- `R` (temps relatif) - <code>&lt;t:0:R&gt;</code> affiche "il y a {deltaUnixYear} ans".

Puis de refermer la syntaxe par le signe plus grand que (<code>&gt;</code>).

Par exemple, le texte suivant :

```
<t:1431476999:t>
<t:1431476999:T>
<t:1431476999:d>
<t:1431476999:D>
<t:1431476999:f>
<t:1431476999:F>
<t:1431476999:s>
<t:1431476999:S>
<t:1431476999:R>
```

Affiche en français, avec comme zone locale la France :

![Mention des timestamps](https://i.dfr.gg/vmdM.png)

:::note
Il est aussi possible de ne pas ajouter de lettre de style.
Il faut alors enlever le dernier `:` tel que : <code>&lt;t:0&gt;</code>.
Cela affiche sous le format par défaut : date longue et l'heure courte (`f`).
:::

### Formatage de liens

<Tabs defaultValue="lien-hypertexte" queryString="formatage-de-liens">
<TabItem value="suppression-embed" label="Suppression d'embed généré">
Afin de supprimer l'embed généré par un lien, il suffit de mettre les signes plus petit que (<code>&lt;</code>) et plus grand que (<code>&gt;</code>) autour du lien en question.

Par exemple, le texte suivant :

```
https://dfr.gg
```

A comme rendu :

![Embed de lien visible](https://i.dfr.gg/bgQk.webp)

Alors qu'avec les signes :

```
<https://dfr.gg>
```

Cela n'affiche pas l'embed :

![Pas d'embed du lien](https://i.dfr.gg/MtYW.webp)
</TabItem>
<TabItem value="lien-hypertexte" label="Lien hypertexte">
Afin de rendre un texte cliquable, tel un lien, il suffit de prendre le format : <code>[texte à afficher](https://example.com)</code>.

Il est aussi possible d'y rajouter un texte dans l'info-bulle, en rajoutant <code>'texte au survol'</code> à l'intérieur des crochets.

![Info-bulle au survol](https://i.dfr.gg/eoWV.webp)

Par exemple, le texte suivant [:](https://printer.discord.com)

```
[Anciennement discord.fr](<https://dfr.gg> 'DFR') : un site à propos de Discord.
```

A comme rendu :

![Lien hypertexte](https://i.dfr.gg/fKoA.webp)

:::note
Il est aussi possible de [supprimer l'embed du lien](?formatage-de-liens=suppression-embed#formatage-de-liens).
:::
</TabItem>
<TabItem value="mailto" label="Adresse email">
Une adresse email peut être rendue cliquable avec le format, dans l'ordre :

1. Le signe plus petit que : <code>&lt;</code>
2. Optionellement suivi de <code>mailto:</code>
3. <code>nom@addresse</code>
4. Optionellement des paramètres tel que l'URI html correspondante au `mailto`
  * Exemple : <code>?subject=Sujet&body=Contenu%20du%20mail</code>
5. Et finissant par le signe plus grand que : <code>&gt;</code>

Par exemple, le texte suivant :

```
Lien simple : <hello@dfr.gg>
Lien avec toutes les options : [lien hypertexte utilisant l'URL mailto](<mailto:hello@dfr.gg?subject=Exemple%20Markdown>)
```

Apparaît tel que :

![Liens des addresses mail](https://i.dfr.gg/dQtA.png)

:::note
Il est uniquement possible de modifier le texte d'une addresse mail quand `mailto:` est utilisé avec le format classique des liens hypertexte.
:::
</TabItem>
<TabItem value="tel-sms" label="Numéro de téléphone">
Il est possible de rendre cliquable un numéro de téléphone en utilisant le format :

1. Le signe plus petit que : <code>&lt;</code>
2. Optionellement <code>tel:</code> ou <code>sms:</code>
3. Le signe plus : <code>+</code>, optionnel si le paramètre précédent est utilisé
4. Le numéro de téléphone
5. Puis fermer avec le signe plus grand que : <code>&gt;</code>

Le texte suivant :

```
Lien simple : <+33 (0)1 23 45 67 89>
Lien utilisant l'URI : <tel:01 23 45 67 89>/<sms:+33(0)123456789>
```

Est affiché comme cela :

![Liens des numéros de téléphone](https://i.dfr.gg/sJgb.png)

:::note
Contrairement à l'addresse mail, il n'est pas possible d'utiliser des liens hypertextes avec des numéros de téléphone.
:::
</TabItem>
</Tabs>

## La mise en forme rapide

Pour faciliter l'utilisation de la mise en forme, Discord a également ajouté une fonctionnalité de mise en forme rapide.
Elle n'est disponible que sur l'application Windows, Linux, MacOS ainsi que l'application Web.

Pour l'utiliser, il suffit de sélectionner avec la souris ou le clavier la zone à modifier.
Plusieurs boutons apparaissent alors afin de mettre en forme le texte, afin de mettre en gras, italique, souligné, barré, en citation, en code ou en spoiler :

![Mise en forme rapide](https://i.dfr.gg/LWIt.png)

## Les raccourcis claviers

Plusieurs raccourcis claviers sont disponible pour gagner du temps lors de la mise en forme.
Pour les utiliser il suffit de sélectionner le texte à mettre forme et effectuer une combinaison de touche comme suit :

- <kbd>Ctrl</kbd> + <kbd>I</kbd> : &#42;<i>Italique</i>&#42;
- <kbd>Ctrl</kbd> + <kbd>B</kbd> : &#42;&#42;<b>Gras</b>&#42;&#42;
- <kbd>Ctrl</kbd> + <kbd>U</kbd> : &#95;&#95;<u>Souligné</u>&#95;&#95;
